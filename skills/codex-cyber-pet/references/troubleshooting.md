# 故障排查

## 目录

1. 仍显示默认机器人
2. 选择后没有变化
3. 宠物显示不全
4. 背景不透明或有彩边
5. 动作少或环视无效
6. 身份漂移与动作跳变

## 仍显示默认机器人

1. 确认 `~/.codex/pets/<id>/pet.json` 与图集同时存在。
2. 检查 JSON 是否可解析，`spritesheetPath` 是否为正确相对路径。
3. 检查配置选择值是否为 `custom:<id>`。
4. 完全退出 Codex（macOS 使用 `Command+Q`）后重开。

## 选择后没有变化

比较应用启动时间与配置/宠物文件修改时间。如果文件在应用启动后写入，当前宠物覆盖层可能仍持有旧缓存。切到其他宠物再切回，或完全退出重启。

不要通过删除整个 Codex 缓存目录解决；这可能影响登录和其他本地状态。

## 宠物显示不全

检查默认单元格 Alpha 包围盒。若底边接近 208（例如 bottom=202，只剩 6 px），运行 `normalize_safe_margins.py`，把内容缩到安全区并保留约 24 px 底边。修复必须应用到所有有效帧，不能只改单张待机图。

## 背景不透明或有彩边

- 确认图集为 RGBA。
- 确认未使用格 Alpha 全零。
- 清除 Alpha=0 像素中的隐藏 RGB。
- 色键边缘需要去色溢处理，但不要重复侵蚀毛发边缘。

## 动作少或环视无效

- v1 是 8×9、1536×1872，仅含标准状态。
- v2 必须是 8×11、1536×2288，并在清单声明 `spriteVersionNumber: 2`。
- 第 9–10 行必须包含 16 个固定顺序方向；仅扩大 v1 画布不算升级。

## 身份漂移与动作跳变

每个动作行都要附主形象和照片。不要把不同生成批次的单帧混进同一动作族。若某个方向失败，重做完整的 8 帧方向行，并重新检查跨行边界。
